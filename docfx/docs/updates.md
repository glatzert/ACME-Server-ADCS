# Updating

If you did not modify the original `appsettings.json` and only made changes to `appsettings.Kestrel.json` and `appsettings.Production.json`, updating is as simple as extracting the new release files to the folder where you deployed ACME-ADCS, e.g. `C:\inetpub\acme`.

Some updates will need adjustments to the config. Those will be listed here.

To check your current version of ACME-ADCS run `ACMEServer.ADCS.exe -v`
